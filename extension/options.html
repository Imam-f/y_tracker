YOUTUBE TAB DESK

Connect this browser

Send YouTube tabs from every window in this profile to your desktop app.

Checking connection…
For another computer, enable Allow local network in the app’s Remote control settings and copy its browser connector address. Required for the /connector endpoint. Copy the Bearer token from the app. Shown as a source tag on your tabs. Local connections use the computer name when blank.

Install this connector in every browser profile you want to track. For network connections, keep the app open on the receiving computer.
